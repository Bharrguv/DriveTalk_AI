Architecture

How DriveTalk works

Simple pipeline you can extend.

1

Caller speaks or types

Optional Whisper STT or direct text. State is kept in LangGraph.

2

Agent decides which tool to use

check_available_slots · book_service_appointment · reschedule · escalate_to_human

3

Mock (or real) API responds

In-memory scheduler for demos. Replace with your DMS in production.

4

Natural reply + TTS

Short, voice-friendly answers played through the edge-tts pipeline.

Run the full stack locally
